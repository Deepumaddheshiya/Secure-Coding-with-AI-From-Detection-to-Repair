# DevGPT Dataset Documentation & Provenance

## 1. Primary Source & Snapshots

- **Dataset Name:** DevGPT (Version 10)
- **Official Repository:** [https://github.com/NAIST-SE/DevGPT](https://github.com/NAIST-SE/DevGPT)
- **Paper Repository:** [https://github.com/vlad2010/MSc_DataEngineering_Results](https://github.com/vlad2010/MSc_DataEngineering_Results)
- **Zenodo DOI:** [10.5281/zenodo.16392320](https://zenodo.org/records/16392320)
- **License:** Open Access / Permissive Academic Reuse

### Snapshots Investigated in the Research Paper:
1. **`snapshot_20231012`** (October 2023 snapshot):
   - Used in the initial October 2024 experiment evaluating GPT-4o.
   - Evaluated 64 candidate files; confirmed 32 vulnerabilities across 26 files.
2. **`snapshot_20240514`** (May 2024 snapshot):
   - Added in the September 2025 experiment evaluating GPT-4.1, GPT-5, and Claude Opus 4.1.
   - Combined total evaluated: 114 candidate files; 56 confirmed vulnerabilities across 48 files.

## 2. Local Repository Status & Availability

In this repository, the benchmark cases analyzed in the September 2025 experiment are preserved locally under:
```
MSc_DataEngineering_Results/
└── DetectAndFix_Data/
    └── 2025_09_24/
        └── DevGPT_v10_snapshot_20240514/
            ├── File_01/ ... File_48/
```

### Structure of Each Case Directory (`File_XX`):
- `Info.txt`: Metadata regarding the discussion URL, GPT model version, original file name, and static scanner detections.
- `source_data_info.txt`: Discussion step, user prompt, and origin metadata.
- `Sharing_.../`: The complete conversational context from DevGPT including `sharing_info.txt` and raw source files.
- `LLMs/`: Historical model response transcripts containing the actual outputs generated by:
  - `claude-opus-4-1-20250805`
  - `gpt-4.1-2025-04-14`
  - `gpt-5-2025-08-07`

---

## 3. Explicit Data Availability Statement

As mandated by Section 1 of the implementation specification:
- The **48 benchmark files** (`File_01` to `File_48`) representing the 56 confirmed vulnerabilities from the paper's final evaluation dataset are **fully present, extracted, and verifiable** in the project directory.
- The raw, unselected multi-gigabyte dump of all 39,013 DevGPT files is accessible via the Zenodo and NAIST-SE archives. Our benchmark harness explicitly utilizes the 48 curated files vetted by the paper authors.
- **No synthetic data** is silently substituted; all benchmark samples originate from actual DevGPT developer-GPT sessions.
